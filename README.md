# YaariBlog - A Modern Laravel Blogging Platform

YaariBlog is a full-stack blogging application built with Laravel, featuring a clean design, real-time search, and a robust admin panel for content management.

## 🚀 Live Demo
Check out the live application here: [YaariBlog on Render](https://yaariblog.onrender.com/)

## ✨ Features
- **Dynamic Content:** Create, edit, and delete blog posts via a secure Admin Panel.
- **AJAX Search & Filter:** Instantly find blogs by title or category without page reloads.
- **Responsive UI:** Fully optimized for mobile, tablet, and desktop views.
- **Category System:** Organise posts into different topics seamlessly.
- **Secure Authentication:** Protected admin routes and encrypted passwords.

## 🛠️ Tech Stack
- **Backend:** PHP 8.2, Laravel 10/11
- **Database:** PostgreSQL
- **Frontend:** Blade, CSS3, JavaScript (AJAX)
- **Deployment:** Docker & Render
